# Wanasa Al Deerah V26

- PostgreSQL V25 baseline migration: Alembic `202609220001`.
- Render pre-deploy migration: `alembic upgrade head`.
- Supabase migration mirror.
- Production schema gate checks `alembic_version` before starting.
- GitHub Actions builds Android AAB, Windows installer, Web and signed iOS IPA.
- Release artifacts are generated by GitHub Actions after secrets are configured.

Required GitHub Actions secrets:
`API_BASE_URL`, `ANDROID_KEYSTORE_BASE64`, `ANDROID_KEYSTORE_PASSWORD`, `ANDROID_KEY_PASSWORD`, `ANDROID_KEY_ALIAS`, `IOS_CERTIFICATE_BASE64`, `IOS_CERTIFICATE_PASSWORD`, `APPLE_TEAM_ID`, `IOS_PROVISIONING_PROFILE_NAME`.

Backend/provider secrets belong in Render/Supabase/your secret manager and must not be committed.
