# V17 Architecture

## التطبيقات
1. Customer App: تصفح، بحث، سلة، طلبات، تتبع، حساب.
2. Merchant App: المنتجات، الأسعار، المخزون، العروض، الطلبات، التقارير.
3. Web Portal: واجهات العميل والتاجر والإدارة عبر المتصفح.
4. Windows Admin EXE: مركز تحكم المنصة.

## الإدارة المركزية
Admin يمكنه إدارة:
- المنتجات والتصنيفات.
- الأسعار.
- العروض والخصومات.
- المخزون.
- التجار والعملاء.
- الطلبات وحالاتها.
- العمولات ورسوم التوصيل.
- المحتوى والواجهات والبانرات.
- إعدادات المنصة.
- المستخدمين والأدوار والصلاحيات.
- السجلات والتدقيق.

## المبدأ
كل الواجهات تتصل بـ API مركزي واحد، وبالتالي أي تعديل إداري على السعر/العرض/المحتوى يظهر على العملاء والتجار وفق الصلاحيات.

## ملاحظة
التحكم الكامل لا يعني تجاوز صلاحيات نظام التشغيل أو سياسات المتاجر؛ النشر والتوقيع والإشعارات والدفع تحتاج إعدادات خارجية لاحقاً.
