# Windows EXE Admin Control Center

هذا المجلد يحدد تطبيق سطح المكتب الإداري المطلوب بناؤه بـ Flutter Windows.

الوحدات:
- Dashboard
- Users/Roles
- Merchants
- Products
- Prices
- Offers
- Banners/UI content
- Inventory
- Orders
- Delivery
- Commissions
- Settings
- Audit Log

التطبيق يتصل بنفس API المركزي. لا يحتوي V17 على ملف EXE مُجمّع مسبقاً.
