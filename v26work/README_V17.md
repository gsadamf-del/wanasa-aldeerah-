# وناسة الديرة V17 Full Platform Foundation

منصة متعددة الواجهات:
- Customer Mobile: Android + iOS عبر Flutter.
- Merchant Mobile: Android + iOS عبر Flutter.
- Web Customer/Merchant/Admin foundation.
- Windows EXE Admin Control Center عبر Flutter Windows.
- FastAPI + PostgreSQL backend.
- JWT/RBAC.
- إدارة المنتجات والأسعار والعروض والمخزون والطلبات.
- إعدادات واجهة المنصة من لوحة التحكم.
- GitHub Actions لبناء Android وWindows وWeb.

هذه نسخة V17 متكاملة كـ source/build foundation وليست APK/EXE مُجمّعة مسبقاً ولا نظاماً إنتاجياً نهائياً.
